C 同学自检实验

任务
维护共用的答案提取和评分规则。用同一规则计算基线与自检结果。
每题沿用原始基线生成初答，再调用模型一次，要求它核对自己的初答并给出最终选项。自检输入由题目、选项和初答构成，参考答案供评分使用。
用同一模型、设备和固定 200 题比较零次自检与一次自检。小组若做自检次数分析，可另加两次自检。

文件位置
experiments/C_self_check 存放自检实现和专用配置。
runs/C_self_check 存放逐题输出、运行配置和汇总。每次试跑或正式评测创建独立运行目录。
analysis/C_self_check 存放对照分析、错题案例和交叉复现记录。
共用评分逻辑在 evaluate_ceval.py，正式题单与参考答案在 data/ceval。

实验记录
逐题保存初答、自检输入、修正后的原始输出、提取选项、参考选项、各次调用耗时和状态。
汇总各科准确率、格式有效率、模型调用次数和耗时，列出答错变对、答对变错及格式变化的题目。
共用基线使用 runs/baseline-20261123-111329。
